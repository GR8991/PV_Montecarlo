# Sample data (optional)

Put a PVsyst report (`.pdf`) and/or an hourly 8760 file (`.csv`, `.xlsx`) in this folder and the app
offers a "Use the sample files" switch when nothing is uploaded.

The `.gitignore` keeps everything in this folder except this README out of Git, so client files are not
published by accident. If your repository is private and you want the sample on Streamlit Cloud,
remove the `sample_data/*` lines from `.gitignore` before committing.
